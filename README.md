# Multiple Linear Regression via OLS (Closed Form)

[![CI](https://github.com/Osamsami/multiple-linear-regression-ols-project/actions/workflows/ci.yml/badge.svg)](https://github.com/Osamsami/multiple-linear-regression-ols-project/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3.11](https://img.shields.io/badge/python-3.11-blue.svg)](https://www.python.org/downloads/)

A from-scratch implementation of multiple linear regression using the **Ordinary Least
Squares (OLS) closed-form (normal equation) solution** — no `statsmodels`, no
`sklearn.linear_model`. The model is fit with plain NumPy on the Kaggle "California
Housing Prices" dataset to predict median house value from housing and location
features.

## Overview

Given a design matrix `X` (with an intercept column) and target vector `y`, the model
solves for the coefficient vector `β` directly via the normal equation:

```
β = (XᵀX)⁻¹ Xᵀy
```

The project covers the full pipeline end to end: data cleaning, categorical encoding,
feature scaling, a held-out train/test split, the closed-form fit itself, evaluation
(RMSE, R²), and diagnostic plots — plus a small serving layer (`train.py` + a Streamlit
app) so the fitted model can be reused outside the notebook.

## Dataset

**Source:** [California Housing Prices](https://www.kaggle.com/datasets/camnugent/california-housing-prices)
on Kaggle. Derived from the 1990 U.S. Census, with each row representing a California
census block group. See the Kaggle listing for the dataset's license terms.

20,640 rows, one row per census block group, with the following columns:

| Column | Description |
|---|---|
| `longitude`, `latitude` | Block group location |
| `housing_median_age` | Median age of houses in the block group |
| `total_rooms`, `total_bedrooms` | Total rooms / bedrooms in the block group |
| `population`, `households` | Population and household counts |
| `median_income` | Median income (tens of thousands of USD) |
| `ocean_proximity` | Categorical: `<1H OCEAN`, `INLAND`, `ISLAND`, `NEAR BAY`, `NEAR OCEAN` |
| `median_house_value` | **Target** — median house value (USD) |

The raw CSV is committed at `data/raw/housing.csv` for reproducibility. Derived
artifacts (`data/processed/`, `outputs/results/predictions.csv`, `models/`) are
regenerated by running the notebook or `train.py` and are not tracked in git.

## Model & Preprocessing

1. Impute missing `total_bedrooms` values with the column median.
2. One-hot encode `ocean_proximity` (`drop_first=True`).
3. 80/20 train/test split (`random_state=42`).
4. Standardize features with `StandardScaler`, fit on the training set only.
5. Prepend a bias (intercept) column and solve the normal equation on the training set.
6. Evaluate on both the training and held-out test sets.

## Results

Metrics from the current train/test split (80/20, `random_state=42`), reproduced by
`train.py`:

| Split | RMSE | R² |
|---|---|---|
| Train | ≈ 68,434 | ≈ 0.650 |
| Test | ≈ 70,061 | ≈ 0.625 |

Train and test metrics are close, which suggests the model generalizes reasonably well
rather than overfitting — though a linear model still leaves a substantial share of the
variance in `median_house_value` unexplained. See `outputs/plots/` for the
actual-vs-predicted and residual diagnostic plots.

## Technologies Used

Python, NumPy, pandas, scikit-learn (splitting, scaling, and metrics only — not the
linear model), Matplotlib/Seaborn, Streamlit, Jupyter.

## Installation

```bash
git clone https://github.com/Osamsami/multiple-linear-regression-ols-project.git
cd multiple-linear-regression-ols-project
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

### 1. Notebook (exploration)

```bash
jupyter lab notebooks/mlr_ols_project.ipynb
```

Run all cells to reproduce data cleaning, the fit, evaluation, and the diagnostic plots
in `outputs/plots/`.

### 2. Train and persist the model

```bash
python train.py
```

Loads `data/raw/housing.csv`, fits the closed-form OLS model on an 80/20 train/test
split, prints train/test RMSE and R², and saves the fitted coefficients and scaler
statistics to `models/ols_model.pkl`.

### 3. Interactive demo (Streamlit)

```bash
python train.py          # if models/ols_model.pkl doesn't exist yet
streamlit run app.py
```

Opens a form for the housing features described above and returns the predicted
median house value along with the fitted model coefficients.

### 4. Docker

```bash
docker build -t mlr-ols .
docker run -p 8888:8888 mlr-ols                 # Jupyter Lab
docker run -p 8501:8501 mlr-ols streamlit run app.py --server.address=0.0.0.0  # Streamlit demo
```
